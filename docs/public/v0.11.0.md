# Gigabrain v0.11.0

Gigabrain v0.11.0 makes memory quieter, safer, and more useful in daily agent work.

## What changed

- Recall is now observational. It does not sync native files, rebuild the world model, or run maintenance.
- Explicit project scope means project-only recall. Personal profile rows require an intentional personal or combined query.
- Cross-store ranking uses reciprocal-rank fusion instead of comparing incompatible per-store scores.
- Queries with at least four informative tokens use a two-token relevance floor, rejecting accidental one-word overlaps unless dense cosine is at least 0.65.
- Automatic recall injection and session brief injection are disabled by default.
- Session-end checkpoint hooks are opt-in and deduplicate on the stable host session id.
- A stable `session_id` limits a session to one structured checkpoint; repeated teardown calls return a deduplicated receipt.
- Native checkpoint sections are grouped in one write instead of repeating headings for every item.
- Stdio MCP servers exit when their client closes stdin or the parent process exits.
- Generated Codex and Claude policy blocks now share one on-demand policy source.

## Privacy

Explicit project recall excludes shared and profile rows across MCP, plugin, and local HTTP surfaces. Local HTTP recall without a scope defaults to shared-only results. Personal profile rows require an intentional personal target or explicit profile scope; regression fixtures cover the project and profile shadows.

The public package runs `scripts/check-no-pii.mjs` during prepack. Public commits, packages, tags, and releases must pass the same scanner.

## Upgrade

```bash
npm install @legendaryvibecoder/gigabrain@0.11.0
```

Existing configs continue to work. To preserve the previous automatic recall and session-prelude behavior, enable both opt-in flags:

```json
{
  "recall": {
    "autoInjectEnabled": true
  },
  "synthesis": {
    "briefing": {
      "includeSessionPrelude": true
    }
  }
}
```

To install the optional Claude teardown checkpoint hook during first-run setup, pass `--session-hook`.
